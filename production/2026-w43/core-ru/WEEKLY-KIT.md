# Lucerna · 俄语周报 VOL.1 — WEEKLY KIT

**Russian core, first pair: Russian text + explanations in the reader's native language (Chinese).**
Week: Mon 2026-10-19 – Sun 2026-10-25 · VOL.1 · 8 pages · built 2026-10-21

This is the Russian target-language core of the Lucerna learner weekly. The Russian
articles were written natively from the Russian trend pool (never translated from
another language's draft); the small gray Chinese text is explanations in the reader's
native language (Chinese) — glosses, exercise instructions, answer notes. Each further
edition of this core keeps the Russian pages and rewrites only the explanations in
another native language.
