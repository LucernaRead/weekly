## §0 总体结论

**11 家中没有任何一家存在 ko R2-1 式缺失。**

- **109/120 版在全部四项计数上干净**（wb=0、pg=0、bl=0、mt=0）。干净的家庭：en、de、fr、it、pt、ru、nl、ja、zh-cn、zh-tw（10 家，共 109 版）。

## §1 方法（每家）

复用 ko 家重校员的方法，通用化为 `inventory_x.py`（ko 的 `inventory_textmd.py` / `inventory_textmd2.py` / `inventory_match.py` 的跨家版）：

1. **从源码 AST 提取每版 150 个编号项**（题干 + 配对词）。跟踪 `CURPAGE[0] = N` 定页码、`.head("…")` 定块、`.ex(level, kind, key, note, stem)` 取题干与键、`.match_set` 取词表与键表。数据驱动项展开 `for … in <列表>` 循环与列表推导式；fr 的 `E[…]` 下标解析同目录 `expl.py` 的 `E = {…}` 字典（315 项）；`reg_ex` 槽位项与写作项以题号 `(N)___` / 60 字核对串做页级核对。
2. **核对口径与 ko 家一致**：全书查（wb）+ 按页查（pg）+ 按块查（bl）+ 配对词独立行查（mt）。另计：块未找到（nf，块头无法定位、只做了页级核对）、变体命中（cp，需第 2–5 级匹配才命中的项数）、无法核实（uv）。
3. **五级 presence 检查**（任一命中即算在场）：(1) exact 规范化子串；(2) compact 去空白子串；(3) answered（题干 `___` 用 key 填回）；(4) scattered（题干 token 按序子序列、最小跨度 ≤200 token）；(5) char-scattered（去空白字符级子序列、锚定前 12 字符、跨度 ≤3000 字符）。
4. **页分区**：按各家页眉格式切分（`## Page P1` / `# Page 1` / `## Página N` / `## Pagina N` / `## 第 N 版` / es、it 的 8 个章节名按序 1–8 等）；只认 1–2 个 `#`（ru 答案区 `### Page N` 小标题不覆盖正页分区）；同页号只取首次出现。
5. **块切分**：练习区起点取练习标题行（`EXERC/ÜBUNG/УПРАЖН/練習/练习/EJERCIC/ESERCIZ/OEFEN` 的严格标题判定：`#` 标题含练习词，或短行以大写练习词 + 分隔符开头）与字母头（`A · …` / `A　…`）两者中较早者；标题行须去 `#` 前缀再比对。pt P7 / fr P7 的语法点 head（`A2 · …`）不是练习块头，已排除。

**校准**：同一套五级方法在 ko 家检出了 R2-1 的 7 道丢项（印版有、text.md 无），证明方法对真实丢弃敏感；en 家 11 版 AST 键序与页码与 `registry.json` 逐项比对均为 OK（regkeys=OK、regpages=OK）。各家置信度均为**高**（源码 AST 提取 150/150 + 页级核对全过）；es 的块级结论置信度为**中**——其 text.md 顺序已打散，块级核对本身不适用，结论以页级为准（见 §4）。

**导出器说明**：ko 修复工人已核查三套导出器（`ru_textmd.py`、`export_zhtw_textmd.py`、`export-textmd-{en,fr,it,nl}.py`）无同款全局去重写法；其余各家导出器代码不在本次审计范围内，本审计以输出物（text.md）为准，不对导出器代码下结论。

## §4 es 专项：块级散射（别机制，非 ko 同根因）

es 11 版 wb=0、pg=0（150 项全在当页），但 bl 每版 100–108、mt 每版 9–11。机制是 **text.md 页内顺序打散**：题干碎片交叉散布于非相邻行甚至跨块，块结构本身在 text.md 里已不存在，块级核对因此失效。这与 ko 的“静默丢弃”不同——ko 是内容没了，es 是内容全在、顺序乱了。

**证据（core-es，`2026-w47-es-zh-cn.text.md`，行号为文件行号）**

- P2：练习标题 `EJERCICIOS　第2版练习` 之后，`A　LAS FECHAS` 与 `B　EL PRESENTE` 两个块头**连续出现**（第 125、126 行），中间无任何题；题干碎片随后以 `A2 / 11. / 16. / 21. / 25–28.` 的编号散列出现；D 块配对词 `25. el debate / 26. el mitin / 27. el cartel / 28. el escaño` 在第 341–344 行，**在 C、D 块头（第 398、402 行）之前**。
