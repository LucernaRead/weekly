# WEEKLY-KIT — Lucerna Russian Weekly, VOL.4 (W47 de)

## 1. Spec

- **Edition:** Russian target-language core, VOL.4; reader language German (de).
- **Issue week:** Monday 16 November – Sunday 22 November 2026. **Issue date:** Monday 16 November 2026.
- **Pairing:** target language Russian × reader native language German (de).
  Masthead `Lucerna`; the top strip reads `КАЖДУЮ НЕДЕЛЮ ПО-РУССКИ · RUSSISCHER TEXT · DEUTSCHE ERKLÄRUNGEN`; the footer on every page reads `Lucerna · RUSSISCHE WOCHENZEITUNG VOL.4 · TEXT AUF RUSSISCH · ERKLÄRUNGEN AUF DEUTSCH` with `Seite N von 8`.
- **Explanation-layer convention:** all explanation is in German — glosses, exercise instructions, answer notes, section furniture and footers. The Russian article text, exercise stems/keys and golden sentences are frozen from the W47 core; only the explanation layer was rewritten. Type names follow the shipped W46 ru-de edition (单选 and 完形单选 both `Ankreuzen`; 完成句子 `Ausfüllen`; 词汇配对 `Zuordnen`; 造句 `Sätze bilden`; 句型转换 `Umformen`; 翻译 `Übersetzen`; 写作 `Schreiben`).
- **Format:** 8 pages (multiple of 4), 1950×2700 px per page, 4 columns, warm ivory paper, dark olive-green accents. Pipeline: Python → SVG → CairoSVG → PNG/PDF.
- **Exercises:** **150 total, continuously numbered 1–150**. By page: P1 10, P2 18, P3 18, P4 18, P5 18, P6 18, P7 12, P8 38. By level: A2 50, B1 76, B2 24. By type: Ausfüllen 54, Ankreuzen 55 (multiple choice 42 + cloze 13), Zuordnen 20, Sätze bilden 12, Umformen 4, Übersetzen 4, Schreiben 1.
  P8 model writing text (“Моя неделя 16–22 ноября”) = **97 words** (brief: 80–100).
- **P7 golden sentences:** 8 sentences, each occurring exactly twice in the issue — once in its own article, once in the P7 “ФРАЗЫ НЕДЕЛИ” list. Page references on P7 are kept in Russian (`Страница N`) in every edition.
- **No invented facts.** See core-ru WEEKLY-KIT.md. The P6 chart is labelled practice data (ЧЕМ ЗАЙМУТСЯ НА ЭТОЙ НЕДЕЛЕ? + “Dies ist eine Übungsumfrage der Redaktion — keine echte Statistik.”) and sums to 100% (38/26/18/18).
