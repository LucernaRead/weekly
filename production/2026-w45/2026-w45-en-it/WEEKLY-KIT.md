## Reproducing the build

- Build tree: `hidden_files/weekly-report-w45-en-it-build/` — `transform.py` (the single source of
  every edition edit; 309 replacements in the final round), `gen_transform.py` (one-off generator:
  started from the verified German edition's round-1 strings, longest-first mapped to Italian, asserting
  on any miss), `run.py` (single-process driver: content12 → 34 → 56 → 7 → 8), `render.py` (cards PNG
  @1950, print PDF, web PDF JPEG q85 @1400), `scratch-checks.py` (supplementary scans, see below),
  per-round baselines `baseline-round1.sha256`, `baseline-round2-pre.sha256`, `baseline-round3-pre.sha256`,
  `baseline-round4-pre.sha256`, build/render logs and `occlusion1/2/3/4*.json`, `diff3.json`.
- Interpreters: `run.py` and `render.py` both run under `tools/venv/bin/python` (Python 3.12.3,
  Pillow 13.0.0). The system python3 (Pillow 10.2.0) has no cairosvg and must not be used for rendering.
- Method: fresh copy of the core build tree → `transform.py` → single-process `run.py` → `render.py`.
  Every repair round re-ran from a fresh core copy with the fixes inside `transform.py` (never a
  content-only edit), and every round recorded the full pre-fix SVG/card/PDF sha256 baseline first.
